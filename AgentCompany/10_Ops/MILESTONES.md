# Milestones

## M0: Company Online

Criteria:

- AgentCompany 入口、宪章、主脑、多脑、部门、员工、沟通、治理、Ops 均存在。
- 当前项目健康风险已写入 War Room 和 Risk Register。
- 新 agent 可按 `00_START_HERE.md` 启动。

## M1: Repository Stabilization

Criteria:

- Git index/worktree 分裂被解释并清理。
- active 测试删除风险被恢复或正式替代。
- Live Coding 构建阻塞被解除并获得 fresh build 证据。

## M2: Core Runtime Safety

Criteria:

- New Game/Continue 存档风险被修复并验证。
- 输入恢复和暂停逻辑有回归测试。
- 关键地图流转路径有验收证据。

## M3: Release Readiness

Criteria:

- Cook 配置、LFS、Localization JSON、资产引用全部通过发布门禁。
- P0/P1 风险清零。
