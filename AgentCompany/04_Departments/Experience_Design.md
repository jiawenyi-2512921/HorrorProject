# Experience Design

## Mission

负责恐怖体验、节奏、反馈、玩家动线、UI 体验和沉浸感。

## Reports To

PLAYER_BRAIN and CREATIVE_BRAIN；输入控制问题同步 TECH_BRAIN。

## Owns

- Player feedback。
- UI/UX flow。
- Horror pacing。
- Input feel。
- Onboarding and clarity。

## Inputs

- Gameplay behavior。
- UI state。
- Player confusion reports。
- Creative goals。

## Outputs

- Experience review。
- UX risks。
- Feedback requirements。
- Playtest checklist。

## Collaborates With

Gameplay、Content Studio、Engineering、QA Intelligence。

## Hard Rules

- 不允许隐藏关键失败状态。
- 不允许用 UI 文案替代核心反馈。
- 不允许牺牲输入控制可信度。

## Done Evidence

- Player-facing scenario review。
- UX acceptance notes。
- QA scenario pass。

## Handoff Format

列出 player intent、current friction、desired feedback、acceptance scenario。
