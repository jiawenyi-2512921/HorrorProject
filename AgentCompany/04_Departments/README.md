# Departments

部门是 AgentCompany 的执行组织。每个任务必须归属一个主责部门，并指定协作部门。

## Department Index

- Executive Command
- Engineering
- Gameplay
- Experience Design
- Content Studio
- QA Intelligence
- Build & Release
- Production
- Research Lab
- Governance & Red Team

## Department File Contract

每个部门必须说明：

- Mission
- Owns
- Inputs
- Outputs
- Collaborates With
- Hard Rules
- Done Evidence
