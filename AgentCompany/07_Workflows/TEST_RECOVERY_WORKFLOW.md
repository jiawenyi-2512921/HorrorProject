# Test Recovery Workflow

## Purpose

Recover trust after tests are deleted, disabled, or stale.

## Steps

1. Inventory deleted tests.
2. Separate active tests from legacy-disabled tests.
3. Count lost test cases and covered behaviors.
4. Decide restore, rewrite, or retire with governance approval.
5. Rebuild minimal tests around high-risk behavior first.
6. Verify tests compile and run.
7. Update test coverage report.

## Priority

1. Save/load and player data.
2. Input lock/unlock.
3. Map travel and game mode bootstrap.
4. Day1 HUD and objective feedback.
5. AI threat runtime.
