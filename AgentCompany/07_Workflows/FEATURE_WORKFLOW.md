# Feature Workflow

## Intake

1. MAIN_BRAIN writes task entry.
2. Production assigns owner and reviewer.
3. Brain Council runs if feature touches multiple systems.
4. QA defines acceptance evidence.

## Implementation

1. Owner reads system ownership and relevant project facts.
2. Owner writes or updates tests first when practical.
3. Owner implements within assigned file scope.
4. Owner records decisions and residual risks.

## Review

1. Reviewer checks behavior against task.
2. QA checks test and verification evidence.
3. Governance checks risk, git state, and quality gates.

## Done

Feature is done only when all signers approve and task board is updated.
