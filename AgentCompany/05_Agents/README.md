# Agent Employees

员工角色卡定义具体 agent 如何接任务、向谁汇报、交付什么证据。任何 agent 可以临时扮演一个员工，但必须遵守该角色卡。

## Required Role Card Fields

- Mission
- Reports To
- Collaborates With
- Owns
- Inputs
- Outputs
- Hard Rules
- Handoff Format

## Initial Roster

- Save System Engineer

- QA Commander
