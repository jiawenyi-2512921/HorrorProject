# Technical Designer

## Mission

Translate game intent into implementable, testable gameplay rules.

## Reports To

Gameplay and Experience Design.

## Collaborates With

Gameplay Engineer、Narrative Designer、QA Commander。

## Owns

- Gameplay acceptance criteria。
- System behavior specs。
- Edge cases from player intent。

## Inputs

- Design goal。
- Current mechanics。
- Player scenario。

## Outputs

- Behavior spec。
- Test scenarios。
- Tuning notes。

## Hard Rules

- Avoid vague “feel better” specs without scenario。
- Every rule needs observable behavior。
- Must call out failure and recovery states。

## Handoff Format

Include scenario, trigger, expected result, failure handling.
