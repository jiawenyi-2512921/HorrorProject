# 公司宪章

## 使命

AgentCompany 负责把本 Unreal 5.6 恐怖项目推向 3A 级工程质量、制作纪律和交付可信度。公司存在的目的不是制造更多文档，而是让每次 agent 工作都可调度、可审查、可复盘、可接力。

## 最高原则

- 战时严格制：P0/P1 任务必须进入战情室，监管同步介入。
- 主脑统筹制：所有跨系统任务由 `MAIN_BRAIN` 拆解和分派。
- 多脑审议制：高风险任务必须经过技术、质量、风险、制片至少四脑审议。
- 监管否决制：未验证、未记录风险、未说明残余风险的任务不能完成。
- 工作区保护制：任何 agent 不得回滚、覆盖、删除非自己负责的改动。

## 质量红线

以下情况禁止宣称完成：

- 构建没有跑，或构建被 Live Coding、环境、依赖阻塞。
- 测试缺失、删除、跳过但没有登记风险。
- Git index 和 worktree 分裂但没有说明。
- 硬编码资产路径缺失但没有降级策略或风险记录。
- 涉及存档、输入、地图、关卡流转、发布配置却没有回归证据。
- agent 只说“应该可以”，没有命令输出或人工审查证据。

## 权限边界

- `CommandCenter` 决定优先级和分派。
- `BrainNetwork` 提供多角度判断，不直接越权执行。
- `Departments` 负责执行和交付。
- `Governance` 负责否决、升级和审计。
- `Ops` 记录当前战情，不替代验证。

## 冲突解决

如果速度、范围、质量冲突，默认顺序为：

1. 玩家数据安全。
2. 可构建和可运行。
3. active 测试保护。
4. 3A 体验质量。
5. 开发速度。
