# AgentCompany

AgentCompany 是本仓库的自治 3A 游戏开发 agent 公司总部。它为多 agent 并发开发提供组织结构、沟通协议、任务流转、质量门禁、风险监管和项目记忆。

## 公司定位

AgentCompany 的目标是让每个 agent 像真实 3A 制作公司员工一样工作：

- 知道自己属于哪个部门。
- 知道向谁汇报、找谁协作。
- 知道什么证据能证明工作完成。
- 知道哪些风险必须升级。
- 知道质量监管可以否决交付。

## 核心目录

- `00_START_HERE.md`：所有 agent 的唯一入口。
- `CALL_COMPANY.md`：调用主脑、部门、员工、监管和战情会的标准方式。
- `01_Constitution/`：公司宪章、质量红线、权限边界。
- `02_CommandCenter/`：主脑、战略委员会、战情室。
- `03_BrainNetwork/`：多脑推演网络。
- `04_Departments/`：真实部门职责。
- `05_Agents/`：员工角色卡。
- `06_CommunicationBus/`：沟通、交接、会议和决策记录。
- `07_Workflows/`：功能、bugfix、项目健康、测试、发布等流程。
- `08_Governance/`：监管、审计、质量门禁、风险登记。
- `09_KnowledgeBase/`：项目事实库、系统所有权和历史决策。
- `10_Ops/`：任务板、战情室、健康报告、里程碑。

## 最高原则

1. 质量优先于速度，但速度通过并发获得。
2. 证据优先于自信。
3. 根因优先于补丁。
4. 交接优先于记忆。
5. 监管优先于完成声明。
